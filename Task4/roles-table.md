# Таблица ролей для RBAC в Kubernetes

| Роль  | Права роли | Группы пользователей |
| --- | --- | --- |
| cluster-admin-role | Полный доступ ко всем ресурсам кластера, включая секреты, узлы, RBAC. Может создавать, изменять, удалять любые ресурсы во всех namespace. | Системные администраторы, DevOps-инженеры, руководители IT-отдела |
| viewer-role | Только чтение всех ресурсов кластера (кроме секретов). Может просматривать pods, services, deployments, configmaps во всех namespace. | Аналитики, менеджеры проектов, стажеры, внешние аудиторы |
| developer-role | Полный доступ к ресурсам в определенных namespace (кроме секретов и RBAC). Может создавать, изменять, удалять pods, services, deployments, configmaps. | Разработчики, QA-инженеры, техлиды проектных команд |
| namespace-admin-role | Полный административный доступ к конкретному namespace, включая секреты и RBAC этого namespace. Может управлять всеми ресурсами в рамках своего namespace. | Владельцы продуктов, лидеры команд разработки, администраторы приложений |
